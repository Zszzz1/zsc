Web 前端的长度单位

CSS Length Units · 张顺昌《高级网页设计》课堂实践

1绝对长度单位

px

像素（pixel）

最常用的屏幕单位。1px 是设备上的一个物理像素点（CSS 意义上约为 1/96 英寸）。

in

英寸（inch）

打印常用。1in = 2.54cm = 96px。

cm / mm

厘米 / 毫米

1cm ≈ 37.8px，1mm ≈ 3.78px，主要用于打印样式表。

pt

点（point）

印刷传统单位。1pt = 1/72in ≈ 1.333px。

pc

派卡（pica）

1pc = 12pt = 1/6in ≈ 16px。

Q

四分之一毫米

1Q = 1/4mm ≈ 0.945px，使用较少。

2相对长度单位

em

相对父元素字号

1em = 父元素的 font-size。常用于 padding、margin 等随文字缩放的场景。

rem

相对根元素字号

1rem = html 根元素的 font-size（默认 16px）。响应式布局的首选单位。

%

百分比

相对于父元素对应属性的值，宽高常用，具有继承连锁性。

vw / vh

视口宽 / 高

1vw = 视口宽度的 1%，1vh = 视口高度的 1%，适合全屏布局。

vmin / vmax

视口较小 / 较大边

vmin 取宽高较小值的 1%，vmax 取较大值的 1%，保证元素不超出视口。

ch / ex

字符单位

ch = 字符"0"的宽度；ex = 小写字母"x"的高度，适合排版控制。

3直观对比

width: 96px
6em
width: 6em（随父级字号缩放）
6rem
width: 6rem（随根字号缩放）
20vw
width: 20vw（随视口缩放）

记忆要点：屏幕布局优先用 rem / vw / vh 实现响应式，px 用于边框等不需要缩放的细节，em 适合组件内部间距，打印场景再考虑 cm / pt。
