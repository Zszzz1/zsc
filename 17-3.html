商品列表（接口数据）

用 fetch() 请求 https://dummyjson.com/products?limit=8， 接口返回一个 JSON 对象：里面有 products（商品数组）、total、skip、limit。 拿到数组后 forEach 遍历，把每件商品渲染成一张卡片；点击卡片可跳转到详情页。

一、接口信息

列表接口： https://dummyjson.com/products?limit=8
详情接口： https://dummyjson.com/products/1（最后的数字是商品 ID）
返回结构：{ "products": [ {...}, {...} ], "total": 100, "skip": 0, "limit": 8 }
