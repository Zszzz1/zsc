电商系统架构图（Canvas 绘制）

整张架构图全部由 canvas 2D 绘制：圆角矩形、连接箭头、文字、图例都用绘图 API 完成，没有使用任何图片。 鼠标移到任意模块上会高亮，并显示该模块的职责说明。

悬停模块查看说明
分层说明：用户层（浏览器 / App / 小程序）→ 接入层（CDN、API 网关、负载均衡）→ 应用层（商品、搜索、用户、订单、支付、库存六大服务） → 中间件层（消息队列、缓存、任务调度、监控日志）→ 数据层（MySQL、Redis、Elasticsearch、对象存储）。
核心 API 为 fillRect()、arc()、moveTo()/lineTo()、fillText()；圆角矩形用 arcTo() 拼出。
