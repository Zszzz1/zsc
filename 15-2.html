JavaScript 程序结构：循环与条件

程序有三种基本结构：顺序结构、条件结构（if...else、switch）和 循环结构（for、while、do...while）。条件结构根据判断结果选择执行路径， 循环结构让一段代码重复执行。下面通过可交互的例子演示这两种结构，所有结果同时输出到页面面板和控制台。

条件结构：if...else 与 switch

if...else if...else：分数判等级

if (zsc_score >= 90) { zsc_result = "优秀"; } else if (zsc_score >= 60) { zsc_result = "及格"; } else { zsc_result = "不及格"; }

switch：星期几查询

switch (zsc_day) { case 1: zsc_name = "星期一"; break; case 6: zsc_name = "星期六"; break; default: zsc_name = "无效数字"; }

循环结构：for、while、do...while

for 循环：九九乘法表（双重循环）

for (var zsc_i = 1; zsc_i <= 9; zsc_i++) { for (var zsc_j = 1; zsc_j <= zsc_i; zsc_j++) { // 内层循环 j 不超过 i } }

while 循环：1 加到 100

var zsc_total = 0, zsc_i = 1; while (zsc_i <= 100) { zsc_total += zsc_i; zsc_i++; }

do...while：至少执行一次

var zsc_k = 1; do { // 先执行，再判断条件 zsc_k++; } while (zsc_k <= 5);
