1什么是 SVG 图标

SVG 图标使用矢量图形描述图标，每个图标是一段独立的 <svg> 代码， 可以无限缩放而不失真，并且能直接用 CSS 修改 stroke、color 等属性。 Lucide 是一套开源的 SVG 图标库，本页面通过本地 cdn/lucide.min.js 将 data-lucide 标记的元素替换为内联 SVG。

4SVG 图标用法速查

步骤代码说明
引入 JS<script src="cdn/lucide.min.js"></script>加载 Lucide 图标库
标记元素<i data-lucide="home"></i>用 data-lucide 指定图标名称
生成 SVGlucide.createIcons()把标记元素替换为内联 SVG
样式控制svg { color: red; width: 2rem; }直接用 CSS 控制颜色与尺寸

记忆要点：SVG 图标是真正的矢量图形，每个图标都是独立的 <svg> 标签，可以通过 CSS 自由控制颜色、大小、线宽等属性，也可以添加 CSS 动画与交互效果，是现代网页图标的主流方案。
