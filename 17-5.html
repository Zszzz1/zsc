JavaScript 的两种定时器

setTimeout：延迟一段时间后只执行一次，用 clearTimeout() 取消。
setInterval：每隔一段时间重复执行，用 clearInterval() 停止。

一、setTimeout：延迟执行一次

点击「延时执行」后，等待设定的秒数，再输出一句话；等待期间点「取消定时器」就调用 clearTimeout() 把它清掉，消息不会出现。

延迟 秒
状态：未启动
点击按钮开始倒计时…

二、setInterval：每隔一段时间重复执行

点击「开始计数」后每 1 秒执行一次回调，计数器加 1；「暂停」调用 clearInterval() 停止，「清零」把计数归零。

0 次（每秒 +1）
状态：已停止 · 定时器 ID：无

三、实战：用 setInterval 做实时时钟

每隔 1 秒触发一次回调，把当前时间写进页面，时钟就会一直走。

五、核心代码

// 1. setTimeout：只执行一次，返回定时器 ID var zsc_t = setTimeout(function () { console.log("3 秒后执行，只执行一次"); }, 3000); clearTimeout(zsc_t); // 取消（还没来得及执行时） // 2. setInterval：每隔一段时间执行一次，返回定时器 ID var zsc_i = setInterval(function () { console.log("每 1 秒执行一次"); }, 1000); clearInterval(zsc_i); // 停止循环
