Mermaid：智能客服系统流程图与 ER 图

用 Mermaid 的文本语法描述图表：流程图（flowchart）刻画智能客服从接入、理解、检索生成到人工兜底与反馈闭环的完整链路； ER 图（erDiagram）刻画用户、会话、消息、知识库、工单与满意度评价之间的数据关系。图表由浏览器端本地脚本渲染，不访问外部 CDN。

一、智能客服系统业务流程图

flowchart TD

四个分组依次为接入层、理解层、检索与生成层、服务闭环；菱形判断节点表示知识召回与置信度校验，虚线表示数据回流驱动知识库与模型迭代。 

flowchart TD
    subgraph S1["接入层"]
        A1["网页 / APP / 小程序"] --> A2["会话创建与身份识别"]
        A3["电话 / 邮件 / 工单"] --> A2
        A2 --> A4["预处理：去噪 · 纠错 · 敏感词审核"]
    end

    subgraph S2["理解层"]
        A4 --> B1["意图识别"]
        B1 --> B2["多轮对话状态跟踪"]
        B2 --> B3{"知识库能否召回?"}
    end

    subgraph S3["检索与生成层"]
        B3 -->|命中| C1["混合检索：BM25 + 向量"]
        C1 --> C2["重排序 Rerank"]
        C2 --> C3["LLM 生成答案 + 引用溯源"]
        C3 --> C4{"置信度达标?"}
    end

    subgraph S4["服务闭环"]
        C4 -->|是| D1["返回答案给用户"]
        B3 -->|未命中| D2["转人工坐席"]
        C4 -->|否| D2
        D2 --> D3["坐席处理 / 创建工单"]
        D3 --> D4["工单归档 + 知识沉淀"]
        D1 --> D5["满意度评价"]
        D4 --> D5
        D5 --> D6["日志与指标回流"]
        D6 --> D7["知识库与模型迭代"]
        D7 -.-> C1
    end

二、核心数据表 ER 图

erDiagram

以会话为中心：一个用户可发起多次会话，会话包含多条消息；消息可触发多次知识召回；召回不当时升级为工单并沉淀知识条目；每次会话最多一条满意度评价。 

erDiagram
    USER ||--o{ CONVERSATION : "发起"
    CONVERSATION ||--|{ MESSAGE : "包含"
    CONVERSATION ||--o{ TICKET : "升级"
    CONVERSATION ||--o| SATISFACTION : "评价"
    AGENT ||--o{ TICKET : "承接"
    MESSAGE ||--o{ RETRIEVAL_LOG : "触发"
    KB_ENTRY ||--|{ QA_CHUNK : "切分"
    QA_CHUNK ||--o{ RETRIEVAL_LOG : "被召回"

    USER {
        bigint user_id PK "用户ID"
        string nickname "昵称"
        string channel "接入渠道"
        datetime created_at "创建时间"
    }

    CONVERSATION {
        bigint conv_id PK "会话ID"
        bigint user_id FK "所属用户"
        string status "bot / agent / closed"
        datetime started_at "开始时间"
    }

    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint conv_id FK "所属会话"
        string role "user / assistant / agent"
        text content "消息内容"
        float confidence "置信度"
        datetime sent_at "发送时间"
    }

    AGENT {
        bigint agent_id PK "坐席ID"
        string name "坐席姓名"
        string skill_group "技能组"
        string work_status "在线状态"
    }

    TICKET {
        bigint ticket_id PK "工单ID"
        bigint conv_id FK "来源会话"
        bigint agent_id FK "承接坐席"
        string priority "优先级"
        string status "处理状态"
    }

    KB_ENTRY {
        bigint entry_id PK "知识ID"
        string title "标题"
        string category "分类"
        datetime updated_at "更新时间"
    }

    QA_CHUNK {
        bigint chunk_id PK "切片ID"
        bigint entry_id FK "所属知识"
        text content "切片文本"
        vector embedding "向量表示"
    }

    RETRIEVAL_LOG {
        bigint log_id PK "日志ID"
        bigint msg_id FK "触发消息"
        bigint chunk_id FK "召回切片"
        float score "相关性得分"
        datetime logged_at "记录时间"
    }

    SATISFACTION {
        bigint rating_id PK "评价ID"
        bigint conv_id FK "所属会话"
        int score "评分 1-5"
        string comment "评价内容"
    }
实体中文含义关键字段
USER用户user_id、channel
CONVERSATION会话conv_id、status
MESSAGE消息msg_id、role、confidence
AGENT人工坐席agent_id、skill_group
TICKET工单ticket_id、priority、status
KB_ENTRY知识条目entry_id、category
QA_CHUNK知识切片chunk_id、embedding
RETRIEVAL_LOG召回日志log_id、score
SATISFACTION满意度评价rating_id、score
