JavaScript 数组常用方法

数组是存放一组有序数据的容器。下面把数组画成一排带下标的彩色格子， 每点一次按钮就能看到方法如何改变数组：push / pop / shift / unshift 增删元素， slice / splice / concat / join 截取与拼接，sort / reverse / indexOf / includes 排序查找， map / filter / reduce 迭代加工。所有结果同时输出到页面面板和控制台。

一、增删方法：数组的“入口”与“出口”

push 从尾部放入、pop 从尾部取出； unshift 从头部放入、shift 从头部取出。 观察格子的高亮动画即可看出元素从哪里进出。

var zsc_fruits = ["苹果", "香蕉", "葡萄", "樱桃", "猕猴桃"]; zsc_fruits.push("西瓜"); // 尾部添加，返回新长度 zsc_fruits.pop(); // 尾部删除，返回被删的元素 zsc_fruits.unshift("草莓"); // 头部添加，返回新长度 zsc_fruits.shift(); // 头部删除，返回被删的元素

二、截取与拼接：slice、splice、concat、join

slice(起, 止) 不修改原数组，切出一段副本（绿框高亮的就是切走的部分）； splice(起, 个数, 新元素...) 会修改原数组，可删可插； concat 合并数组；join("符") 把数组变成字符串。

slice(1, 4) —— 切片，原数组不变

splice(1, 2, "西瓜", "柠檬") —— 剪切替换

concat(["西瓜", "柠檬"]) —— 合并新数组

join(" → ") —— 拼成字符串

zsc_fruits.slice(1, 4); // 取下标1~3，返回新数组 zsc_fruits.splice(1, 2, "西瓜", "柠檬"); // 从下标1删2个，再插入新元素 zsc_fruits.concat(["西瓜", "柠檬"]); // 合并，返回新数组 zsc_fruits.join(" → "); // 返回字符串"苹果 → 香蕉 → ..."

三、排序与查找：sort、reverse、indexOf、includes

sort() 默认按字符串比较（所以 100 会排在 25 前面），要传比较函数 (a, b) => a - b 才是按数字升序； reverse() 倒序；indexOf(值) 返回下标（找不到返回 -1）；includes(值) 返回 true / false。

var zsc_scores = [88, 25, 100, 77, 9]; zsc_scores.sort(); // ["100", "25", "77", "88", "9"] 字符串序 zsc_scores.sort(function (a, b) { return a - b; }); // [9, 25, 77, 88, 100] zsc_scores.indexOf(77); // 2（找不到返回 -1） zsc_scores.includes(100); // true

四、迭代方法：forEach、map、filter、reduce、find

六位同学的分数数组：[88, 45, 92, 67, 73, 59]。 forEach 逐个访问；map 每人加工后返回新数组（如全班加 5 分）； filter 筛选出及格的同学；reduce 把所有值累积成总分； find 找第一个满足条件的值；some / every 判断“有人 / 全都”满足条件。

map(score + 5) 全班加分 → 新数组

filter(score >= 60) 及格名单

reduce 求总分 / find 第一个 ≥ 90

some（有人不及格）/ every（全部及格）

zsc_scores.forEach(function (zsc_v) { console.log(zsc_v); }); var zsc_plus = zsc_scores.map(function (zsc_v) { return zsc_v + 5; }); var zsc_pass = zsc_scores.filter(function (zsc_v) { return zsc_v >= 60; }); var zsc_sum = zsc_scores.reduce(function (zsc_a, zsc_b) { return zsc_a + zsc_b; });
