JavaScript 对象：用「键值对」描述一个事物

数组用下标存数据，对象用键名存数据。一个对象就像一张表格， 装着某个事物的各种属性：名字、年龄、专业、分数……下面把一个学生对象画成 键 : 值 的行， 点按钮就能看到属性的读取、新增、修改、删除，以及 this、for...in、Object.keys() 和构造函数 new 的效果。

一、创建对象与读写属性

对象用一对花括号 { } 定义，内部是 键: 值 的列表，键值之间用逗号隔开。 读取属性有两种写法：点语法 对象.键 和方括号 对象["键"]； 给不存在的键赋值就是新增，delete 可以删掉一个键。

var zsc_student = { … } 共 0 个属性
var zsc_student = { name: "张顺昌", age: 20, major: "数字媒体技术", score: 92, city: "长沙" }; zsc_student.name; // "张顺昌" 点语法 zsc_student["age"]; // 20 方括号：键名可以是变量或含特殊字符 zsc_student.gender = "男"; // 新增属性 zsc_student.score = 95; // 修改属性 delete zsc_student.city; // 删除属性（返回 true） // 第二部分会给它再加一个 introduce 方法：函数也可以作为属性值

二、对象里的方法：函数也能当属性

属性的值不只能是数字和字符串，还可以是一个函数，这时它被称为「方法」。 方法内部用 this 指向调用它的那个对象， 所以 zsc_student.introduce() 能拿到自己的名字； 但如果先把方法赋值给一个普通变量再调用，this 就会丢失。

zsc_student.introduce() —— this 正常

var zsc_fn = zsc_student.introduce; zsc_fn() —— this 丢失

var zsc_student = { name: "张顺昌", age: 20, introduce: function () { return "大家好，我是" + this.name + "，今年" + this.age + "岁。"; } }; zsc_student.introduce(); // this → zsc_student，正常输出 var zsc_fn = zsc_student.introduce; zsc_fn(); // this → 丢失，name 变成 undefined

三、遍历对象：for...in 与 Object 的静态方法

对象不能用 for 按下标循环（对象没有下标），要用 for...in 遍历键名， 再用 对象[键名] 取值。Object.keys() 返回键组成的数组、 Object.values() 返回值组成的数组、Object.entries() 返回 [键, 值] 组成的二维数组，拿到数组之后就能用 forEach / map 了。

for...in 逐个访问

Object.keys() 键名数组

Object.values() 值数组

Object.entries() 键值对数组

in 运算符 / hasOwnProperty() 判断

for (var zsc_key in zsc_student) { console.log(zsc_key + " = " + zsc_student[zsc_key]); } Object.keys(zsc_student); // ["name", "age", "major", ...] Object.values(zsc_student); // ["张顺昌", 20, "数字媒体技术", ...] Object.entries(zsc_student); // [["name", "张顺昌"], ["age", 20], ...] "name" in zsc_student; // true zsc_student.hasOwnProperty("score"); // true

四、构造函数 new 与对象数组

要创建一批结构相同的对象（比如一个班的学生），可以写一个构造函数： 函数名首字母大写，内部用 this.键 = 值 挂属性，调用时前面加 new。 把 new 出来的对象放进数组，就成了「对象数组」——这是真实项目里最常见的数据形态： 先 sort 排序，再 filter 筛选，最后 map 取出需要的字段。

操作结果

function zsc_Student(name, age, major, score) { this.name = name; this.age = age; this.major = major; this.score = score; } var zsc_students = [ new zsc_Student("张顺昌", 20, "数字媒体技术", 92), new zsc_Student("李明", 21, "计算机应用", 78), new zsc_Student("王雪", 20, "视觉传达", 85), new zsc_Student("陈涛", 22, "软件技术", 59) ]; zsc_students.sort(function (a, b) { return b.score - a.score; }); // 按分数降序 zsc_students.filter(function (s) { return s.score >= 80; }); // 筛选 zsc_students.map(function (s) { return s.name; }); // 提取姓名
