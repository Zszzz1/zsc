3实现要点

技术点实现方式
SVG 引入引入 font/iconfont.js 自动注入 SVG symbol 集合
图标引用<svg><use xlink:href="#icon-xxx"></use></svg>
颜色控制通过 CSS fill: currentColor 继承父元素 color
自适应宽度flex: 1 五个导航项均分整行宽度
固定底部position: absolute; bottom: 0 相对手机容器定位
徽章 / 红点绝对定位叠加在图标右上角

记忆要点：SVG symbol 方式通过 <use> 标签引用图标，每个图标只定义一次即可多处复用，通过 fill: currentColor 可以用 CSS 的 color 属性控制图标颜色，配合 flex 布局实现自适应宽度，是现代网页图标的最佳实践。
