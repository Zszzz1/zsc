JSON 数据格式演示

JavaScript Object Notation —— 轻量级的数据交换格式

什么是 JSON

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，采用完全独立于语言的文本格式， 易于人阅读和编写，也易于机器解析和生成。它基于 JavaScript 的对象字面量语法， 是目前 Web 开发中客户端与服务器交换数据最常用的格式（配合 fetch / AJAX 使用）。

字符串 String"张三"（必须双引号）
数值 Number20、3.14
布尔 Booleantrue / false
空值 Nullnull
数组 Array[1, 2, 3]
对象 Object{"键": "值"}

JSON 语法示例

一个典型的 JSON 数据：由对象和数组嵌套组成，键必须用双引号包裹。

{ "name": "张顺昌", "age": 20, "isStudent": true, "hobbies": ["网页设计", "编程", "篮球"], "address": { "province": "山东", "city": "济南" }, "grade": null }

JSON.parse 与 JSON.stringify 互转

JSON.parse()：把 JSON 字符串解析为 JS 对象（接收 → 使用）； JSON.stringify()：把 JS 对象序列化为 JSON 字符串（发送 → 传输）。 左右两栏互为转换结果，可编辑后再转换体验。
