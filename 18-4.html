ECharts 图表演示

引入本地 cdn/echarts.min.js（5.5.1，已下载到项目 cdn 目录，不依赖外网）， 用 echarts.init() 初始化容器，再 setOption() 传入配置对象即可绘图。 两个示例分别对应 ECharts 官方示例库中的 pie-roseType-simple 与 polar-roundCap。

图一 · 基础南丁格尔玫瑰图

官方示例 ↗ 
option = {
  legend: { top: 'bottom' },
  toolbox: {
    show: true,
    feature: {
      mark: { show: true },
      dataView: { show: true, readOnly: false },
      restore: { show: true },
      saveAsImage: { show: true }
    }
  },
  series: [
    {
      name: 'Nightingale Chart',
      type: 'pie',
      radius: [50, 250],
      center: ['50%', '50%'],
      roseType: 'area',
      itemStyle: { borderRadius: 8 },
      data: [
        { value: 40, name: 'rose 1' },
        { value: 38, name: 'rose 2' },
        { value: 32, name: 'rose 3' },
        { value: 30, name: 'rose 4' },
        { value: 28, name: 'rose 5' },
        { value: 26, name: 'rose 6' },
        { value: 22, name: 'rose 7' },
        { value: 18, name: 'rose 8' }
      ]
    }
  ]
};

图二 · 圆角环形图（极坐标 roundCap）

官方示例 ↗ 
option = {
  angleAxis: {
    max: 2,
    startAngle: 30,
    splitLine: { show: false }
  },
  radiusAxis: {
    type: 'category',
    data: ['v', 'w', 'x', 'y', 'z'],
    z: 10
  },
  polar: {},
  series: [
    {
      type: 'bar',
      data: [4, 3, 2, 1, 0],
      coordinateSystem: 'polar',
      name: 'Without Round Cap',
      itemStyle: { borderColor: 'red', opacity: 0.8, borderWidth: 1 }
    },
    {
      type: 'bar',
      data: [4, 3, 2, 1, 0],
      coordinateSystem: 'polar',
      name: 'With Round Cap',
      roundCap: true,
      itemStyle: { borderColor: 'green', opacity: 0.8, borderWidth: 1 }
    }
  ],
  legend: {
    show: true,
    data: ['Without Round Cap', 'With Round Cap']
  }
};
说明：玫瑰图用 roseType: 'area' 让扇区半径随数值变化，itemStyle.borderRadius 做圆角； 图二用 polar 极坐标系 + 两组 type: 'bar' 对比，第二组开启 roundCap 显示圆角端点。 两个图表都带 toolbox（数据视图 / 还原 / 保存图片），可点击右上角工具按钮操作。
