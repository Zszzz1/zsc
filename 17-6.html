Promise / async 异步流程：包饺子

每一步都用 setTimeout 包进 Promise 来模拟耗时：
买原料 → 取原料 →（和面 与 和馅 同时进行）→ 包饺子 → 吃饺子。
并行用 Promise.all()，串行用 await / .then()；页面上实时显示每步进度与总耗时。

四、核心代码

// 用 setTimeout 模拟一个耗时任务，包成 Promise function zsc_sleep(zsc_key, zsc_ms) { return new Promise(function (zsc_resolve) { zsc_set_running(zsc_key); setTimeout(function () { zsc_set_done(zsc_key); zsc_resolve(); }, zsc_ms); }); } // async / await 版：串行 + 并行 async function zsc_make_dumplings() { await zsc_sleep("buy", 6000); // 买原料 6 秒 await zsc_sleep("take", 2000); // 取原料 2 秒 await Promise.all([ // 和面、和馅同时进行 zsc_sleep("dough", 3000), zsc_sleep("filling", 3000) ]); await zsc_sleep("wrap", 4000); // 包饺子 4 秒 await zsc_sleep("eat", 2000); // 吃饺子 2 秒 }
